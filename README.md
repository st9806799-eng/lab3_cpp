# Лабораторна робота №3: Програмування алгоритмів з розгалуженням

Виконав: Шевченко Нікіта Вікторович, група ІСТ-21, варіант 17 (додатковий варіант: 17 + 5 = 22).

## Структура репозиторію

* task1_v17.cpp — розкладання тризначного числа на цифри та підрахунок парних цифр (if)
* task1_v22_alt1.cpp — розкладання тризначного числа на цифри та добуток парних цифр (додатково до варіанту 22, if)
* task2_v17.cpp — виведення назви групи та кількості студентів за кодом (switch, варіант 17)
* task2_v22.cpp — виведення назви сузір'я та кількості зірок за кодом (switch, варіант 22)
* task3_region.cpp — перевірка попадання точки (x, y) у заштриховану область (if...else)

## Компіляція та запуск

`bash
g++ task1_v17.cpp -o task1_v17
./task1_v17

g++ task1_v22_alt1.cpp -o task1_v22_alt1
./task1_v22_alt1

g++ task2_v17.cpp -o task2_v17
./task2_v17

g++ task2_v22.cpp -o task2_v22
./task2_v22

g++ task3_region.cpp -o task3_region
./task3_region
